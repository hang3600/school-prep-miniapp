# 首页设计评审 · 六维打分

> 尺子来自 huashu-design `references/critique-guide.md`。场景 = App UI（最重要：功能性/细节执行；次重要：视觉层级；哲学一致性可放宽）。
> 概念维权重最高且一票否决：概念≤5 分时总评封顶 6.0。
> 评审对象：B 开学时间带落地版（2026-11-22）。

**总体评分：7.6/10（良好）**

| 维度 | 分 | 依据 |
|---|---|---|
| 概念/立意 | 7 | 有从内容长出的 idea：倒计时有形状（四段时间带）、清单抢先看证明「替你想到了」。盖住文字看时间带仍认得「分阶段的开学准备」。但换个「考试倒计时」题材，这套骨架仍成立——母题与内容相关却非不可替换，落在 7。 |
| 哲学一致性 | 8 | 选定方向 B 的核心特征都在：大数字、四段带、当前段绿、form 来自内容、颜色只回答一个问题。无自相矛盾元素。App UI 场景此维可放宽，给 8。 |
| 视觉层级 | 8 | 眯眼测试：绿色大数字 23 最先跳出→时间带当前段→CTA。标题/正文对比 100rpx vs 27rpx 远超 2.5 倍。扣分：首屏辅助小字（原 gray 3.34:1）层级偏弱，本轮已修。 |
| 细节执行 | 7 | 8pt 网格基本遵守、同类间距一致、主色受控（绿+中性灰+暖点缀）。扣分：贴士末行曾有孤字（本轮已修）；部分小字对比度本轮才补齐。 |
| 功能性 | 8 | 每个元素都 earn its place：胶囊预览=价值证明、时间带=阶段提示、宫格=分类入口、CTA=行动。删掉任一都会损失能力。首屏三秒能定位。 |
| 创新性 | 7 | 「时间带」比通用倒计时数字有想法，格子/胶囊是克制表达。但整体仍在工具型 App 的合理范式内，没有「意想不到但很合理」的惊喜决策。 |

### 优点（Keep）
- 概念先于执行：签名物件（时间带）是从内容长出来的，不是风格库抽的。
- 减色成功：全页只有品牌绿一个强调色，颜色只回答「现在在哪一段」。
- 层级干净：大数字是唯一主角，进度降为辅助行，不抢戏。

### 问题（Fix，按严重度）
1. ⚡重要 — 辅助小字对比度 3.34:1 未达 4.5 底线 → 本轮已修（6.68:1）。
2. 💡优化 — 贴士末行孤字 → 本轮已加 `text-wrap: pretty`。
3. 💡优化 — CTA 落在第二屏，首屏无立即行动出口。要露 CTA 必须从首屏摘掉一个模块（学段/范围/胶囊/宫格四选一），属结构取舍，交用户定夺。
4. 💡优化 — 时间带等宽而非按天数比例（详见 polish-log「不改」说明）。

### 快速修复清单（若只有 5 分钟）
- [x] 小字对比度提到 4.5:1 以上
- [x] 消除末行孤字
- [ ] （需用户确认）首屏 CTA 露出方案

### 结论
概念立得住（7 分，不触发一票否决），执行在工具型 App 里属中上。两处执行瑕疵本轮已修。剩余两项是结构取舍，不是缺陷——**不建议为它们大改**，符合用户此前否掉极简大改的偏好。
