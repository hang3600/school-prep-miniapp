## 优点（Keep）

- **首页时间带**：skill 概念维说的「从用户内容里长出来的独有 idea」——把抽象倒计时画成有四段刻度的带，换个产品名就不成立。这是全app最值钱的资产，务必保住。
- **令牌单源执行到位**：`app.wxss` 一套变量贯穿，换色（企业蓝→成长绿）能系统性落地，图标用脚本从同一份 token 生成。工程上的一致性远超一般小程序。
- **清单页三态与微交互**：未备/已备好/已装包三态用「空框/圆点/打勾」区分，配合勾选弹跳动画与进度条平滑推进——这是 skill 说的「每一屏的事件」，做得扎实。
- **完成态有始有终**：`done-card` 收尾 + 复制/分享 + 下一分类引导，工具型产品最容易缺的闭环，这里补上了。
- **按压反馈全覆盖**：几乎每个可点元素都有 `hv-press` + transition，细节执行的产品意识在线。

## 问题（Fix）

### 1. 可读性底线：打磨环只修了首页，其余 8 页没同步 — ⚡重要
- 当前：首页辅助小字已从 `--gray` #8C8A80 提到 `--ink-2` #5C5A50（6.68:1）；但 category/progress/profile/reminder/checklist 仍大面积用 `--gray`。实测对比度：
  - 全局 `--gray` on 暖白 = **3.34:1**（skill 硬线 4.5，不达标）
  - 进度页 `cat-sub` #a7a398 on 白 = **2.52:1**，`locked .badge-state` on 灰底 = **2.19:1**
  - 清单页 `done-sub` #6b7688 on 暖白 = **4.24:1**（略欠）
- 问题：skill 明确「正文对比度 ≥4.5:1，任何风格不豁免」。上次打磨只覆盖了首页，等于把标准执行了一半。
- 修复：把 `--gray` 从 #8C8A80 调到 ≈#6E6C62（对暖白 ≥4.5:1），一处令牌改动全站受益；进度页 `#a7a398`、`#d8d5c9` 两个硬编码灰改 `var(--gray)`；`done-sub` 改 `var(--ink-2)`。

### 2. 进度页双主角 + 信息重复三遍 — ⚡重要
- 当前：顶部大橙渐变卡（连续7天 + 76rpx 大数字）与下方成片绿进度条并列；每个分类行「33% + 进度条填充 + 已装包 4/12 件」同一件事说三遍。
- 问题：眯眼测试下有两个视觉焦点，视线不知先落哪；橙与绿都是高饱和强色，没有主次。skill「颜色只回答一个问题」在这里失效。
- 修复：streak 卡的橙降级为绿系浅底（与全局令牌一致），大数字保留；分类行删掉百分比数字或删掉「已装包 N/M」其一（进度条已经在表达进度）。**注**：用户已否掉极简方向，故建议「降饱和不删结构」，不动卡片形态。

### 3. 模板装饰三处（skill 明确要删） — 💡优化
- 分类页 intro「军训必备 · 宿舍用品 · 住校必备 · 行李箱整理，7大分类全覆盖」——「A · B · C」中点堆砌 + 与下方「开学物品全部分类」标题语义重复，且实测断行出孤字「盖」。建议整行删除，标题已完整表达。
- 我的页三个数据卡的「进行中 / 坚持中 / 继续加油」——数据本身即信息，趋势标签是凑数文案。
- 进度页成就三格用同一枚奖杯图标——技能说「该是图的地方放真的图」，三个不同成就用同一图标像占位符；至少按解锁态区分视觉重量。

### 4. 首页概念没有向其他页延伸 — 💡优化（结构问题，本轮不建议动）
- 首页有「时间带」母题，内页全是通用卡片列表。理想状态是分类/进度页也带一点「行李/格子/刻度」的影子，但这属结构改动，且用户已否掉整体风格大改——本轮只标记，不擅动。
