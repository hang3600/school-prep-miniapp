# 开学清单内容参考（竞品拆解）

> 来源：GitHub 竞品 `liuyi886-maker.github.io`「大学新生开学清单」，从其前端打包 JS 提取的清单数据。

> 用途：作为我们清单「内容深度 + 提醒文案 + 四态勾选」的参考底稿。共 **10 大类 / 172 件**。

> 提取日期：2026-11-22。竞品为大学新生向，我们做学段差异化时需按学段裁剪。

## 1. 证件材料（15 件）

**一句提醒**：原件、复印件和电子备份分开放

**分类说明**：学校要求可能不同，出发前再对照录取通知书核对一次。

**通用物品**：

- 录取通知书
- 高考准考证
- 身份证原件
- 身份证正反面复印件
- 户口本主页和本人页复印件
- 一寸和二寸证件照
- 证件照电子版
- 团员证或党员材料
- 团组织或党组织关系转接材料
- 个人学籍档案（切勿拆封）
- 学校指定银行卡
- 少量现金
- 贫困证明或助学贷款材料（需要者）
- 户口迁移证（需要者）

**男生专属**：

- 兵役登记证（学校要求且已满18周岁时）

## 9. 药品健康（16 件）

**一句提醒**：少量常用药和个人长期用药

**分类说明**：药品按个人情况准备，注意有效期和禁忌，不确定时咨询医生或药师。

**通用物品**：

- 个人长期使用的处方药
- 创可贴
- 碘伏棉签或消毒棉片
- 体温计
- 口罩
- 常用感冒药
- 退烧止痛药
- 肠胃药
- 止泻药
- 过敏药（按个人情况）
- 跌打损伤外用药
- 润喉片
- 花露水
- 风油精或清凉油
- 眼药水（按需）
- 个人医疗信息和紧急联系人记录

## 10. 军训用品（16 件）

**一句提醒**：防晒、补水和减少磨脚

**分类说明**：军训安排以学校通知为准，不要自行混用药物。

**通用物品**：

- 军训鞋垫
- 替换鞋垫
